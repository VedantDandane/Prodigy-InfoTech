Interactive Navigation Menu Project

This is a Web Development Internship task project.

Features:
1. Fixed navigation menu visible on all page sections.
2. Navbar changes style when the page is scrolled.
3. Menu items change color and style on hover.
4. Active menu item is highlighted based on the current section.
5. Responsive hamburger menu for mobile screens.
6. Professional landing page design using HTML, CSS, and JavaScript.

Files:
- index.html
- css/style.css
- js/script.js

How to run:
1. Extract the ZIP file.
2. Open the project folder.
3. Double-click index.html.
4. The project will open in your browser.

Optional VS Code method:
1. Open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Click "Open with Live Server".
