Interactive Navigation Menu

A fixed navigation bar that changes its style on scroll and highlights menu items on hover. Built using HTML, CSS, and JavaScript.

Explore Project

About This Project

This project demonstrates a responsive and interactive navigation menu. The menu stays fixed at the top of the screen and remains visible while scrolling through the page.

Fixed Navbar

The navigation bar remains visible on all sections of the webpage.

Scroll Effect

The background, shadow, and size of the navbar change when the page is scrolled.

Hover Effect

Menu items change color and style when the user hovers over them.

Features

HTML Structure

Clean semantic HTML is used to structure the navigation menu and page sections.

Professional CSS

Modern styling, transitions, shadows, gradients, and responsive design are included.

JavaScript Interactivity

JavaScript detects scrolling and adds dynamic classes to update the navbar style.
